# 🌍 AI Multilingual Translator

An AI-powered multilingual translation application built with **Gradio** and **Hugging Face Transformers** using the **Facebook NLLB-200 Distilled 600M** model.

The application enables users to translate text between multiple languages through a modern, simple, and interactive interface.

---

## 🚀 Features

- 🌍 Translate text between multiple languages
- 🤖 Powered by Facebook NLLB-200
- 🔄 Swap source and target languages
- 🧹 Clear input and output fields
- 📊 Real-time text statistics (Characters & Words)
- 📥 Download translated text as a TXT file
- 📝 Built-in translation examples
- 🎨 Modern and responsive Gradio interface
- 🌐 Supports multiple languages including:
  - Arabic
  - English
  - French
  - German
  - Spanish
  - Italian
  - Turkish
  - Russian
  - Chinese (Simplified)
  - Japanese
  - Korean
  - Hindi
  - Portuguese
  - Dutch
  - Greek
  - Polish
  - Swedish

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/AI-Multilingual-Translator.git
```

### Navigate to the project folder

```bash
cd AI-Multilingual-Translator
```

### Install dependencies

```bash
pip install -r requirements.txt
```

### Run the application

```bash
python app.py
```

## 💻 User Interface

The application provides an intuitive interface where users can:

- Enter or paste text.
- Select the source language.
- Select the target language.
- Translate instantly.
- View text statistics.
- Download the translated text.
